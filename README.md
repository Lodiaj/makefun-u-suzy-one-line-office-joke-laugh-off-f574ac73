## The line

> I asked for a raise and got a standing desk, so now I can stand up for myself while still being underpaid.

One original one-line joke about office life. The punchline twists "stand up for yourself": the raise request is answered with furniture, so the worker ends up literally standing — and still underpaid. No setup to explain, no office cliché, just the pun landing in one read.

## How it works

`main.ts` (Node 22, TypeScript run as-is) validates the line (1–200 characters, not only whitespace) and writes it to `/output/entry.txt`. Run it with:

```sh
node main.ts
```

`OUTPUT_DIR` overrides the output directory (defaults to `/output`).
